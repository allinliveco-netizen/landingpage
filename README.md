# ALL IN LIVE

Responsive landing page inspired by the supplied ALL IN LIVE brand images and fluid-light video reference. Frequency is the selected default; the four earlier directions remain available through their `?design=` URLs.

Run `npm run dev`, then open http://127.0.0.1:5173. No installation or build required. Deployable files live in `dist/`.

Features: procedural WebGL liquid lighting, a continuously rotating vinyl sculpture with pointer tilt and its own pause control, floating photo prints, scroll reveals, seven-image horizontal gallery, keyboard-accessible full-screen photograph viewer, cinematic venue parallax, reading progress, global motion control, system reduced-motion support, mobile navigation, service accordions, email and Instagram contact links.

Venue photography crops derive from the supplied promotional artwork. No unsupported customer counts, client logos or testimonials are used. Email actions open the visitor's mail client; no messages are sent automatically. Fonts load from Google Fonts with system fallbacks.
